Fehlerbilder

ProblemPrüfen
Hermes antwortet nichtProvider-Login, Modellwahl, Internet, Rate Limit.
LM Studio nicht erreichbarModell geladen, Server läuft, URL/Port korrekt, Firewall lokal.
Tools funktionieren lokal schlechtModell unterstützt Tool Calling? Kleiner Test mit einem Tool.
SOUL.md wird nicht gelesenDateipfad und UTF-8-Codierung prüfen; keine ANSI-/Legacy-Codierung.
Port 4173 belegtDer Workshop-Server wählt automatisch den nächsten freien Port. Terminalausgabe beachten.
Android erreicht Präsentation nichtnpm run start:lan, gleiches WLAN, Windows-Firewall, angezeigte LAN-IP.

Im Zweifel stoppen

Wenn Ziel, Datenquelle, Berechtigung oder Auswirkung unklar ist: Agentenlauf stoppen, Vorschau prüfen und eine engere Aufgabe formulieren.

Leitplanken sind Teil des Systemdesigns, nicht nur Teil des Prompts.
