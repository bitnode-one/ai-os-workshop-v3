Handout 01

Hermes Desktop Quickstart

Direkte Installation für Windows und Linux. Docker ist optional und wird im Kernworkshop nicht benötigt.

← HandoutsPräsentationNächster Schritt: Übungen

Vorbereitung

  • Aktuelles Windows 11 oder unterstützte Linux-Distribution.
  • Stabile Internetverbindung für Download und Cloud-Modelle.
  • Mindestens 5 GB freier Speicher für App, Cache und Übungsdateien.
  • Für den Einstieg: Nous-Portal-Konto oder unterstütztes ChatGPT-Codex-/Grok-Abo.

Offizielle Dokumentation: Installation · Quickstart

Windows: Desktop-Installer oder PowerShell

Empfohlen für Einsteiger: Den signierten Hermes-Desktop-Installer über die offizielle Installationsseite laden und ausführen.

Alternative mit konkreten Befehlen

PowerShell ohne Administratorrechte öffnen:

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Nach Abschluss alle PowerShell-Fenster schließen, ein neues öffnen und prüfen:

Get-Command hermes
hermes --version
hermes desktop

Für den schnellen Start mit Nous Portal:

hermes setup --portal
  1. Nur die offizielle URL verwenden und Sicherheitsdialoge aufmerksam prüfen.
  2. Hermes Desktop starten und einen separaten Workshop-Ordner wählen, z. B. Documents\AI-OS-Workshop.
  3. Zuerst eine harmlose Textfrage ohne Datei- oder Toolzugriff testen.
PATH-Hinweis: Wenn hermes nach der Installation nicht gefunden wird, ein neues Terminal öffnen. Die native Installation liegt standardmäßig unter %LOCALAPPDATA%\hermes.

Linux: Hermes Desktop installieren

Der folgende Weg ist für Debian/Ubuntu formuliert. Er installiert die von Hermes dokumentierten Voraussetzungen, Hermes Agent und anschließend die Desktop-App.

1. Voraussetzungen

sudo apt update
sudo apt install -y git curl xz-utils build-essential

2. Hermes Agent installieren

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

3. Shell neu laden und Installation prüfen

source ~/.bashrc
hermes --version
hermes doctor

Bei Zsh stattdessen source ~/.zshrc verwenden.

4. Hermes Desktop bauen und starten

hermes desktop

Der erste Start kann länger dauern, weil die Desktop-Abhängigkeiten installiert und die Electron-App für das lokale System gebaut werden.

5. Nous Portal verbinden

hermes setup --portal
  1. Nur einen separaten Workshop-Arbeitsordner freigeben.
  2. Zuerst Chat und Modellverbindung testen.
  3. Danach Datei- und Toolzugriffe schrittweise aktivieren.
Andere Distributionen: Paketnamen unterscheiden sich. Das Installationsskript unterstützt weitere glibc-basierte Distributionen, aber die aktuelle Plattformmatrix und Installationsanleitung haben Vorrang.

Hermes richtet Hermes ein

Hilf mir, Hermes sicher und anfängerfreundlich einzurichten.
Stelle mir nacheinander höchstens 10 kurze Fragen zu:
1. meinen wichtigsten Aufgaben,
2. meinem Erfahrungsstand,
3. gewünschtem Ton und Arbeitsstil,
4. erlaubten Datenklassen,
5. Aktionen, die immer eine Freigabe benötigen,
6. bevorzugten schnellen und starken Modellen,
7. erlaubten Arbeitsordnern,
8. Inhalt meiner SOUL.md,
9. optionalem Voice-/TTS-Modus,
10. einem sicheren ersten Test.

Erkläre vor jeder Entscheidung kurz die Konsequenz.
Zeige vor jeder Dateiänderung eine Vorschau und frage mich um Freigabe.
Speichere keine Passwörter, API-Schlüssel oder Tokens in SOUL.md.

SOUL.md – sichere Startvorlage

# Arbeitsweise
- Antworte klar, freundlich und ohne unnötigen Fachjargon.
- Stelle Rückfragen, wenn Ziel, Datenquelle oder Freigabegrenze unklar sind.
- Trenne Fakten, Annahmen und Empfehlungen.

# Sicherheitsgrenzen
- Nichts senden, veröffentlichen, kaufen oder löschen ohne explizite Freigabe.
- Vor Dateiänderungen Zielpfad und geplante Änderung anzeigen.
- Keine Geheimnisse oder personenbezogenen Daten dauerhaft speichern.

# Qualitätsstandard
- Bei aktuellen Informationen Datum und Quellen nennen.
- Unsicherheit und widersprüchliche Quellen sichtbar machen.
- Nach Abschluss geänderte Dateien und offene Punkte zusammenfassen.
