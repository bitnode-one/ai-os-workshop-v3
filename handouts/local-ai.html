Handout 03

Lokale KI mit LM Studio

Rechner prüfen, Modell auswählen, lokalen Server starten und mit Hermes verbinden.

1. Hardware mit Hermes prüfen

Hilf mir bei der Wahl eines lokalen LLM für LM Studio.
Ermittle ausschließlich lesend:
- Betriebssystem und Architektur,
- CPU,
- installierten RAM,
- GPU-Modell,
- dedizierten und gemeinsam genutzten Grafikspeicher,
- freien Speicherplatz,
- relevante Treiberinformationen.

Frage danach nach meinen Aufgaben, gewünschter Geschwindigkeit,
Kontextlänge und Datenschutzanforderungen.
Empfiehl drei Optionen:
1. sicher und schnell,
2. ausgewogen,
3. experimentell.
Nenne jeweils Modellgröße, Quantisierung, erwartete Grenzen und Speicherbedarf.
Installiere oder lade noch nichts herunter.
Wichtig: Hardwareangaben des Herstellers sind nur der Ausgangspunkt. Auf dem tatsächlichen Workshop-Gerät prüfen.

2. LM Studio installieren

Windows

  1. Offiziellen Installer von lmstudio.ai laden.
  2. Installieren und starten.
  3. In Discover ein instruct-fähiges GGUF-Modell wählen.

Linux

  1. Aktuelles offizielles Linux-Paket laden.
  2. Ausführbar machen oder distributionsgerecht installieren.
  3. App starten und Modell laden.

Aktuelle Anforderungen: LM Studio system requirements. Derzeit werden 16 GB RAM und 4 GB dedizierter VRAM empfohlen.

3. Modell auswählen

ProfilStartpunktTypische Aufgabe
Sicher3B–7B, Q4Klassifikation, Zusammenfassung, Extraktion
Ausgewogen7B–14B, Q4Schreiben, einfache Analyse, begrenzte Tools
Experimentellgrößer / längerer KontextNur wenn Speicher und Geschwindigkeit reichen

Tool-Aufrufe separat testen: Ein gutes Chatmodell ist nicht automatisch ein guter Agentenmotor.

4. Local Server starten

  1. Modell vollständig laden.
  2. Developer-Bereich öffnen.
  3. Local Server starten.
  4. Adresse notieren, standardmäßig häufig http://127.0.0.1:1234/v1.

Offizielle Server-Dokumentation

5. Hermes verbinden

Provider type: OpenAI-compatible
Base URL: http://127.0.0.1:1234/v1
API key: lm-studio
Model: exakt der in LM Studio angezeigte Modellname
  • Zuerst einfacher Chat-Test.
  • Dann strukturierte Ausgabe testen.
  • Erst danach Datei- oder Toolzugriff testen.
  • Bei Fehlern Modellname, Serverstatus und URL prüfen.
